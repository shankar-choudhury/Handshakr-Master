Welcome to Handshakr! Handshakr is an app that secures and facilitates private agreements, ranging from official marketplace interactions to casual on-the-fly deals. Why Handshakr?
Decentralized - Handshakes are verified P2P through bluetooth
Secure - Handshake details are encrypted and only available to users who made the deal; administrators cannot access details of encrypted Handshakes!
Safe - Handshakr web server guarantees user data integrity secured login
Fair - Price analysis tools allows user to validate agreement

This is the master repo containing all four components of the Handshakr app. Please check the README of each directory to get a more detailed description of that component. 

Please visit https://handshakr.duckdns.org to see the functional website! Download the .apk file on android phones to create a secret and encrypted handshake agreement!
