
# Welcome to Handshakr 🤝

**Handshakr** is a secure, decentralized platform designed to facilitate private agreements—ranging from formal marketplace transactions to informal, real-time deals.

### 🔍 Why Handshakr?

- **🔗 Decentralized:** Handshakes are verified peer-to-peer (P2P) over Bluetooth, with no central authority required.
- **🔐 Secure:** All handshake details are end-to-end encrypted and accessible *only* to the involved parties. Even administrators cannot view encrypted handshake data.
- **🛡️ Safe:** The Handshakr backend ensures data integrity and secure authentication through a hardened Spring Boot web server.
- **⚖️ Fair:** Integrated price analysis tools empower users to make informed, transparent agreements.

---

## 🗂️ Project Structure

This is the **master repository**, containing all four core components of the Handshakr system. For detailed information on each module, please refer to the individual `README.md` files located in their respective directories.

- `backend/` – Spring Boot API for authentication and handshake management  
- `frontend/` – Web client for user interaction  
- `mobile/` – Android application for Bluetooth-based handshake creation  
- `scraper/` – Price comparison and analysis engine
